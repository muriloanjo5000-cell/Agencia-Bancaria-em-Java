Sobre o Sistema

Informações gerais da aplicação e estrutura das telas.

Esta interface reúne as telas base do sistema em um único arquivo HTML para facilitar a prototipação e a integração com seu backend ou API REST.

  • Menu: atalhos rápidos para os módulos principais.
  • Cadastro: formulário para criação de novos registros.
  • Movimentações: lançamento de operações com tipo, valor e data.
  • Listagem: consulta tabular com filtro por texto e categoria.
  • Sobre: documentação resumida do projeto.
